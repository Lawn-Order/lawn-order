## Kostenlos veröffentlichen mit GitHub Pages
1. GitHub-Konto anlegen.
2. Neues Repository z. B. `lawn-order` erstellen.
3. Den Inhalt dieses Ordners hochladen.
4. Repository > Settings > Pages öffnen.
5. Unter Build and deployment: Deploy from a branch auswählen.
6. Branch `main`, Ordner `/root` auswählen und speichern.
7. Nach der Veröffentlichung zuerst die von GitHub erzeugte Adresse testen.
8. Danach unter Settings > Pages die Custom Domain `lawn-order.de` eintragen.
9. Die von GitHub angezeigten DNS-Werte bei deinem Domainanbieter setzen.
